# CERT Académico by RedCiber.org

Plataforma educativa de ciberseguridad/IA con rutas de aprendizaje interactivas (quiz, flashcards, memoria, H5P, video). Sin backend: la autenticación y el progreso viven en `localStorage`.

## Stack

React 19 · TypeScript · Vite 6 · Tailwind CSS (CDN) · Framer Motion 12

Ver [ARCHITECTURE.md](ARCHITECTURE.md) para el detalle de la estructura y el flujo de pantallas.

## Correr localmente

**Requisitos:** Node.js

1. Instalar dependencias:
   `npm install`
2. Ejecutar la app:
   `npm run dev`

## Otros comandos

- `npm run build` — build de producción
- `npm run preview` — sirve el build de producción localmente
